# Архивация Memory Bank

Архивировать текущий прогресс и начать с чистого листа.

## Когда использовать
- Завершён спринт/итерация
- Закончена крупная фича
- Tier 3 переполнен (>8K токенов)
- Начинается новый этап проекта

## Выполнение
!`python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/memory-sync.py" --archive 2>/dev/null || echo '{"error": "Ошибка архивации"}'`

## После архивации

1. **Покажи результат:**
   - Куда сохранён архив
   - Что было в старом progress

2. **Предложи обновить контекст:**
   - Нужно ли обновить activeContext.md?
   - Есть ли решения для записи в decisions.md?

3. **Новый progress:**
   - Какая цель нового этапа?
   - Какие первые шаги?

## Структура архива
```
memory-bank/
└── archive/
    ├── progress-20260115-143022.json
    ├── progress-20260110-091545.json
    └── ...
```

## Важно
- Архивы не удаляются автоматически
- При необходимости можно восстановить контекст из архива
- Периодически чисти старые архивы (>3 месяцев)
