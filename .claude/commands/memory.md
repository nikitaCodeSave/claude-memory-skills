# /memory — Просмотр Memory Bank

Прочитай `memory-bank/memory.json` и покажи пользователю текущее состояние памяти проекта.

## Формат вывода

```
📦 Проект: {meta.project}
🎯 Фокус: {focus}

📋 Лог ({количество} записей):
  ✓ [дата] task — текст
  → [дата] decision — текст (причина)
  ✗ [дата] bug — текст
  • [дата] note — текст
```

## Инструкции

1. Прочитай `memory-bank/memory.json`
2. Выведи информацию в читаемом формате
3. Если файл не существует — предложи создать через `/remember`
