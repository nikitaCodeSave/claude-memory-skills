# /archive — Архивировать память

Архивирует текущий лог и очищает память для нового цикла.

## Что делает

1. Копирует `memory-bank/memory.json` → `memory-bank/archive/YYYY-MM-DD.json`
2. Очищает `log` (оставляет последние 3 записи для контекста)
3. Сохраняет `meta` и `focus`

## Инструкции

1. Прочитай `memory-bank/memory.json`
2. Создай папку `memory-bank/archive/` если не существует
3. Сохрани полную копию в `memory-bank/archive/{сегодняшняя_дата}.json`
4. Обнови `memory.json`:
   - `meta.lastSession` = сегодняшняя дата
   - `log` = последние 3 записи из старого лога
5. Сообщи пользователю:
   - Сколько записей архивировано
   - Путь к архиву
   - Сколько записей осталось

## Когда использовать

- Лог стал слишком длинным (> 30 записей)
- Завершён большой этап работы
- Начинается новая итерация проекта
