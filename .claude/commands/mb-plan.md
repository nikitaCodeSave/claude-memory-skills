# Создание плана разработки

Создай план для: $ARGUMENTS

## Текущий контекст
@memory-bank/snapshot.md
@memory-bank/activeContext.md

## Алгоритм

### 1. Анализ
- Понять цель из `$ARGUMENTS`
- Проверить `backlog.json` на связанные задачи
- Оценить сложность

### 2. Структурирование плана

```markdown
# План: [Название]

## Цель
[Чёткое описание результата]

## Предусловия
- [ ] [Что должно быть готово]

## Шаги (5-10 максимум)
1. [ ] [Шаг] — [оценка времени]
2. [ ] [Шаг] — [оценка времени]
...

## Критерии готовности
- [ ] [Критерий 1]
- [ ] [Критерий 2]

## Риски
| Риск | Вероятность | Митигация |
|------|-------------|-----------|

## Оценка: [X часов/дней]
```

### 3. Сохранение в Memory Bank

**activeContext.md:**
- Обновить "Текущий фокус" → цель плана
- Добавить первые шаги в "Активные задачи"

**progress.json:**
- `track.name` → название плана
- `track.description` → цель
- `nextSteps` → первые 3 шага

**backlog.json** (если план большой):
- Создать items для каждого крупного шага
- Установить зависимости между ними

### 4. Подтверждение
- Показать план пользователю
- Спросить подтверждение перед сохранением
- После подтверждения — сохранить и обновить snapshot
