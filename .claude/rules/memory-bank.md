# Memory Bank Rules

## Автоматическое поведение

При старте сессии контекст из `memory-bank/memory.json` загружается автоматически через SessionStart hook.

## Когда обновлять память

Используй `/remember` для сохранения:

1. **Выполненные задачи** — после успешного завершения
2. **Архитектурные решения** — с причиной выбора
3. **Найденные/исправленные баги** — для истории
4. **Важные заметки** — что может понадобиться позже
5. **Смена фокуса** — при переключении на новую задачу

## Типы записей

```
/remember <текст>                    → task
/remember decision: <текст> — <причина>  → decision
/remember bug: <текст>               → bug
/remember note: <текст>              → note
/remember focus: <текст>             → обновляет focus
```

## Гибридный режим

- **Автоматически**: логируй выполненные задачи если уверен в результате
- **Спрашивай пользователя**: для архитектурных решений или неясных ситуаций

## Архивация

При большом логе (> 30 записей) предложи `/archive` для очистки.
