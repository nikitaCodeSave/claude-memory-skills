# Описание проекта

## Обзор
**Название проекта**: Claude Skills
**Версия**: 0.1.0
**Создан**: 2026-01-17
**Последнее крупное обновление**: 2026-01-17

## Основная цель
Коллекция кастомных skills для Claude Code — автоматизация рабочих процессов,
расширение возможностей агента через многоразовые инструкции и протоколы.

## Целевые пользователи
- Основные: Разработчики, использующие Claude Code
- Вторичные: Команды, стандартизирующие workflow с Claude

## Ключевые требования
1. Skills должны быть модульными и переиспользуемыми
2. Документация в формате SKILL.md с валидным YAML frontmatter
3. Интеграция с Memory Bank для сохранения контекста между сессиями
4. Поддержка slash-команд для быстрого вызова

## Критерии успеха
- [ ] Набор базовых skills (memory-bank, skill-creator, reading-gmail)
- [ ] Memory Bank система полностью функциональна
- [ ] Документация соответствует best practices Anthropic

## Вне скоупа
- Интеграция с внешними API без явного запроса
- Автоматическая публикация skills в реестры
