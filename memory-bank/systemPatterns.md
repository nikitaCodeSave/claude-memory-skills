## Дизайн API

### REST конвенции
- Множественное число для ресурсов: `/users`, `/orders`
- HTTP методы: GET (чтение), POST (создание), PUT (обновление), DELETE (удаление)
- Коды статусов: 200 (OK), 201 (Создано), 400 (Плохой запрос), 404 (Не найдено), 500 (Ошибка)

### Формат ответа
```json
{
  "success": true,
  "data": {},
  "error": null
}
```
